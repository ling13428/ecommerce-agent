# 烬狐 TM9 镁合金无线鼠标

## 产品定位

采用镁合金外壳的轻量化无线鼠标，面向追求极致重量和强度的竞技玩家。TM9 采用 对称 外形，搭载 PAW3950 HS 传感器，最高 36000 DPI，整机重量 约 48g。

## 核心卖点

- **传感器**：PAW3950 HS 传感器，最高 36000 DPI，适合 FPS、MOBA 和日常使用。
- **重量**：约 48g，属于轻量化鼠标，适合快速甩枪和长时间游戏。
- **回报率**：8000Hz 回报率，降低输入延迟。
- **连接方式**：支持2.4G/有线，可按场景切换。
- **微动与按键**：烬狐光微动，6 个可编程按键，支持驱动自定义。

## 适合的场景

1. FPS 游戏中的快速甩枪和精准定位。
2. 长时间办公、学习或游戏使用。
3. 需要多设备切换的笔记本和平板用户。
4. 喜欢轻量化鼠标或特定握姿的玩家。

## 购买前建议确认

- 确认手长和握姿，选择对称或右手人体工学外形。
- 确认重量偏好：轻量化适合快速甩枪，偏重鼠标握持更稳。
- 确认是否需要无线、蓝牙或只使用有线。
- 确认是否需要高 DPI、高回报率或可编程按键。
