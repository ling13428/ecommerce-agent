# 烬狐 GM3 Pro 有线游戏鼠标

## 产品定位

面向预算有限或追求稳定有线连接的游戏鼠标，强调传感器性能和耐用性。GM3 Pro 采用 对称 外形，搭载 PAW3395 传感器，最高 26000 DPI，整机重量 约 61g。

## 核心卖点

- **传感器**：PAW3395 传感器，最高 26000 DPI，适合 FPS、MOBA 和日常使用。
- **重量**：约 61g，重量适中，兼顾稳定性和灵活性。
- **回报率**：1000Hz 回报率，降低输入延迟。
- **连接方式**：支持有线，可按场景切换。
- **微动与按键**：欧姆龙微动，5 个可编程按键，支持驱动自定义。

## 适合的场景

1. FPS 游戏中的快速甩枪和精准定位。
2. 长时间办公、学习或游戏使用。
3. 需要多设备切换的笔记本和平板用户。
4. 喜欢轻量化鼠标或特定握姿的玩家。

## 购买前建议确认

- 确认手长和握姿，选择对称或右手人体工学外形。
- 确认重量偏好：轻量化适合快速甩枪，偏重鼠标握持更稳。
- 确认是否需要无线、蓝牙或只使用有线。
- 确认是否需要高 DPI、高回报率或可编程按键。
