# 烬狐 VK87 磁轴键盘 使用、保养与常见问题

## 首次使用

1. 使用 USB-C 数据线连接电脑，等待系统自动识别。
2. 如需改键、调节触发键程或灯效，前往官网下载并安装烬狐 Hub。
3. 首次使用建议先充满电，并确认键位布局与系统语言一致。
4. 在文本编辑器或游戏里逐个测试按键，确认没有连击或失灵。

## 日常保养

- 定期用干燥软布擦拭键帽和外壳，避免液体从轴体缝隙进入。
- 可拆卸键帽可用清水冲洗，晾干后再装回，不要使用酒精直接喷洒。
- 长期不用时建议保持约一半电量，每隔三个月补电一次。
- 避免在键盘上方饮食，碎屑进入轴体可能影响手感。

## 常见问题

**Q：VK87 支持哪些连接方式？**
A：支持有线。直接使用 USB 数据线连接设备，无需配对。

**Q：磁轴和机械轴有什么区别？**
A：磁轴通过磁场变化触发，支持可调触发键程和快速重置；机械轴手感更直接，结构成熟，按游戏类型和个人习惯选择。

**Q：支持热插拔吗？**
A：不支持热插拔，轴体为固定结构；如轴体损坏或手感异常，请联系售后检测。

**Q：回报率是多少？**
A：标称 1000Hz 回报率，具体以驱动显示为准。

**Q：支持 Mac 吗？**
A：兼容 Windows 10/11、macOS 12+、Linux；部分功能键和驱动功能可能因系统版本不同而有差异。

**Q：键帽打油或磨损怎么办？**
A：本款使用 PBT 双色注塑，日常用干燥软布擦拭；磨损明显时可联系售后购买替换键帽。

**Q：出现连击或按键失灵怎么办？**
A：先更换数据线或 USB 接口排查连接问题，再在驱动中恢复默认设置；仍无法解决时联系售后检测。
