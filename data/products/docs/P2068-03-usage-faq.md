# 烬狐 TM9 镁合金无线鼠标 使用、保养与常见问题

## 首次使用

1. 为鼠标充满电，插入 2.4G 接收器并打开电源开关。
2. 安装烬狐 Hub后调整 DPI、回报率和按键功能。
3. 在鼠标垫上移动几次，确认传感器定位正常。
4. 根据桌面空间和握姿调整 DPI 档位，再进入游戏。

## 日常保养

- 定期用干燥软布擦拭外壳和按键，避免汗渍长时间附着。
- 脚贴磨损后及时更换，保持鼠标移动顺滑。
- 无线鼠标长期不用时建议保持约一半电量，每隔三个月补电一次。
- 不要自行拆解鼠标，以免影响保修和内部排线。

## 常见问题

**Q：怎么连接或配对？**
A：支持2.4G/有线。2.4G 模式插入接收器并打开电源；有线模式直接连接 USB-C 数据线。

**Q：DPI 怎么调？**
A：最高36000 DPI，可通过驱动或机身按键切换档位；建议根据游戏和桌面空间选择。

**Q：回报率是多少？**
A：8000Hz 回报率，高回报率会增加耗电，长时间办公可适当降低。

**Q：续航和充电怎么样？**
A：内置600mAh电池，续航受回报率、灯效和使用频率影响；建议开启省电模式并关闭不用的灯效。

**Q：出现双击怎么办？**
A：本款使用烬狐光微动，出现双击可先在驱动中调整去抖时间；仍无法解决时联系售后检测。

**Q：脚贴可以更换吗？**
A：可以，使用与原厂尺寸匹配的脚贴；更换前清洁底面，避免灰尘影响顺滑度。

**Q：适合什么握姿？**
A：对称，适合抓握、趴握等常见握姿；建议根据手长和握姿选择。

**Q：驱动支持哪些系统？**
A：支持 Windows 10/11、macOS 12+，部分高级功能需要安装烬狐 Hub。
