# 烬狐 AH5 Pro 头戴式游戏耳机 使用、保养与常见问题

## 首次使用

1. 使用 USB-C 数据线连接耳机，等待系统识别。
2. 在系统声音设置中将耳机设为默认播放和录音设备。
3. 安装烬狐 Hub后可调整环绕声、麦克风增益和均衡器。
4. 首次使用建议先以中等音量试听，确认左右声道和麦克风正常。

## 日常保养

- 耳罩和头梁可用干燥软布擦拭，避免液体进入发声单元。
- 不要拉扯耳机线材和麦克风杆，收纳时避免过度弯折。
- 长期不用时建议保持约一半电量，每隔三个月补电一次。
- 耳罩老化或破损时联系售后更换同型号配件。

## 常见问题

**Q：怎么连接？**
A：支持三模。有线模式使用 USB-C 数据线；2.4G 模式插入接收器；蓝牙模式通过配对键进入配对。

**Q：麦克风没声音怎么办？**
A：本款为可拆卸降噪麦克风，先确认麦克风已插紧并在系统输入设备中选中；再检查驱动中的麦克风增益。

**Q：7.1 环绕声怎么开？**
A：本款支持虚拟 7.1，需要安装烬狐 Hub并在驱动中开启；部分主机平台不支持虚拟环绕声。

**Q：续航多久？**
A：内置1000mAh电池，续航受音量、灯效和连接方式影响；建议关闭不用的灯效并控制音量。

**Q：耳罩可以更换吗？**
A：可以，联系售后购买同型号耳罩；拆卸时不要拉扯线材。

**Q：支持 PS5 或 Switch 吗？**
A：兼容 PC、PS5、Switch、手机（视接口而定）；部分平台的语音和环绕声功能需要额外设置。

**Q：有底噪或电流声怎么办？**
A：先更换 USB 接口或缩短线材距离，排除供电干扰；仍存在时联系售后检测。

**Q：戴久了夹头怎么办？**
A：整机重量约 285g，可适当调整头梁长度和耳罩角度；不要强行掰扯头梁。
