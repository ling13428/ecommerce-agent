# 烬狐 MK98 Pro 机械键盘 使用、保养与常见问题

## 首次使用

1. 将模式开关拨到有线或 2.4G 档位，连接电脑后等待系统自动识别。
2. 如需改键、调节触发键程或灯效，前往官网下载并安装烬狐 Hub。
3. 首次使用建议先充满电，并确认键位布局与系统语言一致。
4. 在文本编辑器或游戏里逐个测试按键，确认没有连击或失灵。

## 日常保养

- 定期用干燥软布擦拭键帽和外壳，避免液体从轴体缝隙进入。
- 可拆卸键帽可用清水冲洗，晾干后再装回，不要使用酒精直接喷洒。
- 长期不用时建议保持约一半电量，每隔三个月补电一次。
- 避免在键盘上方饮食，碎屑进入轴体可能影响手感。

## 常见问题

**Q：MK98 Pro 支持哪些连接方式？**
A：支持三模。有线模式使用 USB-C 数据线；2.4G 模式插入接收器；蓝牙模式通过配对键进入配对。

**Q：轴体手感怎么选？**
A：烬狐机械轴 Pro（预润），红轴偏线性、茶轴有轻微段落、青轴段落感更强，建议按游戏和打字习惯选择。

**Q：支持热插拔吗？**
A：支持，更换轴体前请断开电源，并确认轴体引脚规格。

**Q：回报率是多少？无线模式也能达到吗？**
A：标称 1000Hz 回报率；无线模式会根据续航和稳定性自动调整，具体以驱动显示为准。

**Q：支持 Mac 吗？**
A：兼容 Windows 10/11、macOS 12+、Linux；部分功能键和驱动功能可能因系统版本不同而有差异。

**Q：键帽打油或磨损怎么办？**
A：本款使用 PBT 双色注塑，日常用干燥软布擦拭；磨损明显时可联系售后购买替换键帽。

**Q：电池续航多久？**
A：内置4000mAh电池，续航受灯效、回报率和连接方式影响；建议开启省电模式延长使用时间。

**Q：出现连击或按键失灵怎么办？**
A：先更换数据线或接收器排查连接问题，再在驱动中恢复默认设置；仍无法解决时联系售后检测。
