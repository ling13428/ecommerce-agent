# 烬狐 BH5 Pro 头戴式蓝牙耳机 使用、保养与常见问题

## 首次使用

1. 长按电源或配对键进入蓝牙配对，在系统蓝牙列表中选择耳机。
2. 在系统声音设置中将耳机设为默认播放和录音设备。
3. 安装烬狐 Hub后可调整麦克风增益和均衡器。
4. 首次使用建议先以中等音量试听，确认左右声道和麦克风正常。

## 日常保养

- 耳罩和头梁可用干燥软布擦拭，避免液体进入发声单元。
- 不要拉扯耳机线材和麦克风杆，收纳时避免过度弯折。
- 长期不用时建议保持约一半电量，每隔三个月补电一次。
- 耳罩老化或破损时联系售后更换同型号配件。

## 常见问题

**Q：怎么连接？**
A：支持蓝牙 5.3。长按电源或配对键进入配对状态，在系统蓝牙列表中选择设备连接。

**Q：麦克风没声音怎么办？**
A：本款为内置双麦，先在系统输入设备中选中耳机麦克风并确认未静音；再检查驱动或系统增益。

**Q：7.1 环绕声怎么开？**
A：本款不支持虚拟 7.1 环绕声，可通过设备或播放软件自带的音效增强。

**Q：续航多久？**
A：内置1200mAh电池，续航受音量、灯效和连接方式影响；建议关闭不用的灯效并控制音量。

**Q：耳罩可以更换吗？**
A：可以，联系售后购买同型号耳罩；拆卸时不要拉扯线材。

**Q：支持 PS5 或 Switch 吗？**
A：兼容 PC、PS5、Switch、手机（视接口而定）；部分平台的语音和环绕声功能需要额外设置。

**Q：有底噪或电流声怎么办？**
A：先远离路由器、手机等无线干扰源，重新配对并调整音量；仍存在时联系售后检测。

**Q：戴久了夹头怎么办？**
A：整机重量约 280g，可适当调整头梁长度和耳罩角度；不要强行掰扯头梁。
