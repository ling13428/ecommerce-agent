# 退货运费、运费险与包装要求

## 运费承担

质量问题退换货，来回运费由店铺承担；七天无理由退货，寄回运费由买家承担。偏远地区、港澳台及海外订单的运费按实际物流报价处理。运费参考标准如下，实际以物流揽收价格为准。

## 运费参考

| 商品类别 | 无理由退货运费 | 质量问题退货运费 | 说明 |
|---|---|---|---|
| 键盘 | 12–20 元 | 0 元 | 按实际重量和距离计算 |
| 鼠标 | 8–12 元 | 0 元 | 含普通快递 |
| 耳机 | 10–15 元 | 0 元 | 含普通快递 |
| 配件 | 6–10 元 | 0 元 | 键帽、脚贴等 |

## 运费险

订单含运费险的，买家寄回后可在线申请理赔。理赔金额以保险公司核定为准，一般覆盖首重运费，不覆盖保价费、包装费和偏远地区附加费。运费险理赔不影响商品退款进度。

## 包装要求

请使用原包装或同等强度的包装，键盘和耳机建议加缓冲材料，避免运输磕碰。因包装不当导致商品损坏的，可能影响退款金额或换货判定。
