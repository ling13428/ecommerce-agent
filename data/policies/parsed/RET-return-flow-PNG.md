# 退换货流程

七天无理由 / 十五天质量问题

1. 提交申请：订单详情页选择退货或换货

2. 店铺初审：24小时内完成审核

3. 寄回商品：按页面地址寄回并填写单号

4. 质检确认：3-7个工作日完成检测

5. 退款/换货：原路退款或安排换新
